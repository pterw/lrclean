### Task P12: a stall that ends `stage` or `purge` prints the batch and the journal on stderr first (#30)

**Behaviour.** Cause: when a drive stalls, `mover_seams.watch` writes the `stalled` line and calls `ctx.seams.abort(5)` (mover_seams.py:139), which in a real run is `os._exit` (the default of `main`, cli.py:946), so the process ends inside `watch` and prints nothing: exit 5, empty stdout and stderr. `cli._stalled` (cli.py:731-735, called at 792 and 840), which would name the batch and the journal, runs only when `abort` returns, that is only in tests; and it prints to stdout, which `os._exit` does not flush when the output is redirected (probed: stdout 0 bytes, stderr and a flushed stdout 9 bytes).
